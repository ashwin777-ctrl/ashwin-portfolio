# Ashwin Chandrasekar - Personal Portfolio Website

A clean, modern, and professional personal profile and portfolio website created for **Ashwin Chandrasekar**, B.Tech Computer Science and Engineering student at **SRM Institute of Science and Technology (SRMIST)**, Vadapalani Campus (Class of 2027).

> **Academic Task:** Created for the academic assignment under **InAmigos Foundation**.

---

## 🌟 Key Features

- **Design System:** Sleek, modern **Dark Mode** canvas (`#0b0f19` / `#0f172a`) with elevated navy-slate cards (`#131b2e`), electric blue accents (`#2563eb`, `#38bdf8`), subtle glow shadows, and crisp typography.
- **Theme Toggle:** Built-in interactive theme switch button in the navigation bar to toggle between Dark Mode and Light Mode with saved preferences in `localStorage`.
- **High-Contrast Call-to-Actions:** Bold, clearly visible primary button ("View My Projects") with smooth hover animations and glowing depth.
- **No Heavy Dependencies:** Built using pure, standard **HTML5, CSS3, and Vanilla JavaScript**. Fast load times and zero build setup required.
- **Accessible & Semantic:** Structured HTML5 landmarks (`header`, `main`, `section`, `article`, `footer`) and clear ARIA labels.
- **Verified Content:** Accurate details for college, projects, GitHub repositories, and research focus areas without placeholder statistics or artificial claims.
